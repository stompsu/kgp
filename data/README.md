# Data

- `peaks.json`: the 28 official Korona Gór Polski peaks (name, range, height per https://kgp.info.pl/wykaz-szczytow/).
  Coordinates are the OpenStreetMap summit node linked in each peak's `sources` (verified 2026-11-17). Known disputes about which summit is really the highest are recorded in `notes`.
  The app always uses the official KGP peak.
- `osm/parking.geojson`, `osm/trails.geojson`: parking and marked hiking routes near each summit, generated by `scripts/import_osm.py` from Overpass (see the script header for the exact query and date). One feature per peak and OSM object: every feature has `properties.peakSlug`; otherwise the properties are those in `docs/api.md` (M3). `osm/import-report.md` lists counts per peak and any peak with no trails or parking.
  Re-run the import to refresh; the backend reloads the files on startup.
- `scripts/`: offline import scripts (Overpass). Never called from the browser.
